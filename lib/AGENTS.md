# lib/ (leader-scoring)

The venue-neutral library `Leader_scoring`. Data flows
`History` -> `Track_record.build` -> `Metrics.compute` -> `Score.rank`, with
`Copyability`, `Alerts` and `Model` beside it and `Report` tying them together.

- `model_data.ml` is generated by a dune rule from
  `../models/leader-forward-sharpe-gbdt/model.json`; never edit or commit it.
- `Metric.name` strings are part of the model's feature schema and of JSON consumers
  (hl-leaderboard, hl-copy-api): never rename one.
- Keep `Synthetic` deterministic for a seed: the training data depends on it.

Build and test from the repository root as in [../AGENTS.md](../AGENTS.md).
